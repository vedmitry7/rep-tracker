# Локальный запуск

## Админка

- Всё, что относится к админке (команды, кнопки, сообщения и отчёты), оформляй только на английском языке. Не добавляй для админки локализации или переводы.

## Работа с базой данных

- Если задача требует изменения схемы, создавай и применяй миграции к локальной БД, а также выполняй другие необходимые действия с БД для реализации и проверки задачи.
- Изменения схемы должны быть безопасны для уже работающего production: предпочитай миграции только вперёд, сохраняй совместимость при развёртывании и проверяй upgrade до `head`.
- Не изменяй пользовательские данные без явной задачи на это: не переименовывай упражнения, не удаляй и не «исправляй» результаты, пользователей, историю или иные существующие данные ради удобства миграций либо тестов.
- Сервер и production-БД не трогай без отдельной явной просьбы пользователя.

- Когда пользователь просит запустить бота для этого проекта, запускай процессы локально, не в Docker.
- Если API меняли в текущей работе или API ещё не запущен, запусти его командой `python -m fastapi dev api/app/main.py`.
- Затем запусти бота отдельной локальной командой `python -m bot.app.main`.
- Не поднимай Docker-сервисы `api` или `bot`. Для локального запуска используется уже работающая общая БД `shared_local_postgres`.
